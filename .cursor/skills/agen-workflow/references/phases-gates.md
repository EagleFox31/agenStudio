# Phases & Gates — AgenStudio

## Gate G1 — Fondations
- Git init + CI (lint, check, audit)
- Env vars configurées (.env.example → .env)
- Design tokens Tailwind opérationnels
- Composants UI de base (Button, Card, Container, Section, Tag, Reveal)
- `npm run build` vert

## Gate G2 — Design OK
- Toutes les pages maquettées 360 → 1920
- DA sign-off ≥ 4/5 sur les 6 critères (Premium, Créatif, Moderne, Pro, Africain, Flamboyant)
- 0 placeholder visuel
- Formulaire contact fonctionnel

## Gate G3 — Contenu OK
- Copy FR/EN final dans i18n.ts
- 3+ projets JSON complets
- Meta SEO toutes pages
- 0 « À valider » bloquant

## Gate G4 — Go-Live OK
- Build prod vert
- Formulaire testé (Turnstile + Resend + rate limit KV)
- RGPD validé (politique + mentions légales)
- Lighthouse ≥ 90 perf · ≥ 95 a11y
- npm audit 0 vulnérabilité

## Critères Design Review (/5, min 4/5 chacun)

| Critère | Question |
